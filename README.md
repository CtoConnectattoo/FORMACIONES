# FORMACIONES

Repositorio que agrupa los distintos proyectos y materiales utilizados en las formaciones.

## Estructura

```
FORMACIONES/
├── proyectos/   # Un subdirectorio por proyecto o formación
├── recursos/    # Material compartido entre formaciones (plantillas, datasets, imágenes…)
└── README.md
```

## Cómo añadir una nueva formación

1. Crea una carpeta en `proyectos/` con un nombre descriptivo, p. ej. `proyectos/curso-ia-emprendedores/`.
2. Incluye dentro un `README.md` con: objetivo, público, duración y materiales.
3. Haz commit y push.
